#  Мой первый DevOps проект: Python + Docker

Этот проект демонстрирует базовые навыки контейнеризации приложений. Я упаковал простое веб-приложение на Python в Docker-контейнер для обеспечения переносимости и стабильности работы.

## 🛠 Стек технологий
- **Язык:** Python
- **Инструмент:** Docker
- **ОС:** Linux (Ubuntu/CentOS)

## 📦 Что внутри?
- `app.py` — исходный код веб-сервера.
- `Dockerfile` — инструкция для сборки Docker-образа.

## ⚙️ Как запустить?

Если у вас установлен Docker, выполните следующие команды в терминале:

1. Соберите образ:
   ```bash
   docker build -t my-first-app .
